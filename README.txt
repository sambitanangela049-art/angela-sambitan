ANGELA SAMBITAN — PERSONAL PORTFOLIO

Files:
- index.html
- styles.css
- script.js
- assets/

Features:
- Full-screen cinematic hero using the supplied studio background
- Pink / black / plum palette
- Responsive mobile navigation
- Scroll-reveal animations
- Animated marquee
- Cursor glow on desktop
- Scroll progress bar
- Interactive photo gallery + fullscreen lightbox
- Responsive layout for desktop, tablet, and mobile
- About, Journey, Skills, Gallery, Favorites, and Contact sections

To run:
1. Keep the assets folder beside index.html.
2. Open index.html in a browser.
3. For best results, use a local server such as VS Code Live Server.
